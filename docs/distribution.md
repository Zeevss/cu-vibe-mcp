# Поставка из GitHub — 0.3.0

Репозиторий является устанавливаемым плагином. Runtime, навык и manifest находятся в одном дереве. Установка по Git URL или ZIP релиза получает одну согласованную версию. Общий сервер каталога удалён; браузер, cookies, HTTP-запросы к вузу и локальные выгрузки обслуживает пользовательский runtime.

`mcp.json` задаёт portable stdio-конфигурацию с `${PLUGIN_ROOT}`; `.mcp.json` использует совместимый `${CLAUDE_PLUGIN_ROOT}`. Генератор `tools/client_config.py` выдаёт абсолютные пути для самостоятельных desktop-клиентов. В MCP instructions есть необходимые указания для работы без навыка/терминала.

Сборщик включает только разрешённые файлы. В `repository.json` записываются GitHub repository и revision релиза. `release.json` и SHA256SUMS описывают ZIP. Хеш позволяет проверить целостность скачанного архива, но сам по себе не заменяет доверие к источнику. Версия зависимостей закреплена `uv.lock`.

Проверка обновлений ограничена GitHub API; не читает cookies и не отправляет учебные данные. Ответы ограничены по размеру и времени. Ошибки и успешные проверки кешируются на 24 часа отдельно для репозитория, версии и revision. При смене установленной версии старый кеш не переиспользуется. Запрос `force` обходит TTL; opt-out запрещает и явные проверки. Проверка уведомляет, а установку выполняет пользователь или менеджер плагинов.

Различаются новый стабильный релиз и изменение default branch. Последнее может быть только правкой документации. Для установки без известного commit `repository_changed=null`. Runtime не выдаёт отсутствие релизов за актуальность ветки.

Старые Docker Compose/каталог/nginx и отдельный сетевой bootstrap больше не используются. Ранее запущенный локальный контейнер остановлен. Папка с cookies и глобальная конфигурация прежнего MCP не менялись.

Пределы: обычному облачному чату нужна работающая MCP-связь с компьютером, а не просто текст SKILL.md. Для ChatGPT подготовлен путь через Secure MCP Tunnel; для Claude Desktop — local stdio. Подтверждение подключения конкретного аккаунта/приложения требует реального tool call в этом клиенте.

Проверка 15.11.2026: 78 тестов прошли, включая настоящий Chromium на локальной форме, stdio, compact discovery/batch и ошибки GitHub/кеша. Lint, форматирование и проверка навыка прошли. Самостоятельный пакет запускался отдельным stdio-клиентом без реальной сессии портала. Workflow проверен локально как YAML; GitHub Actions, ChatGPT Tunnel и приложение Claude пока не запускались в реальных аккаунтах.

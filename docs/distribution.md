# Поставка из GitHub — 0.4.0

Источник: [Zeevss/cu-vibe-mcp](https://github.com/Zeevss/cu-vibe-mcp). Runtime, навык и manifest находятся в одном дереве. Git-клон или ZIP релиза содержит согласованную версию. Текущий пользовательский сценарий — обычный ChatGPT через Secure MCP Tunnel, описанный в [README](../README.md) и [инструкции подключения](chat-clients.md).

`tools/client_config.py` по умолчанию печатает команду для ChatGPT с абсолютными путями. Основные инструкции включены в MCP: подключение может работать без отдельной установки навыка и без терминала у модели. Совместимые manifest для прежних клиентов сохранены, но не входят в текущую инструкцию установки и не подтверждают тестирование этих приложений.

`login` использует HTTP SSO и локальный скрытый ввод. `auth_login` в чате возвращает инструкцию; пароль/OTP через MCP не принимаются. Selenium остаётся только для чтения силлабусов Note. Подробнее: [протокол SSO](sso.md).

Сборщик включает только разрешённые файлы, включая runtime, lock-файл и документацию SSO. В `repository.json` записываются GitHub repository и revision сборки. `release.json` и `SHA256SUMS` описывают ZIP. Хеш проверяет целостность, но не заменяет доверие к источнику. Зависимости закреплены `uv.lock`; cookies и загрузки в поставку не входят.

Проверка обновлений использует только публичные метаданные GitHub, без cookies или учебных данных. Результаты кешируются на 24 часа по repository/version/revision. `force` обходит TTL; `LMS_MCP_CHECK_UPDATES=0` отключает обращения. Новый стабильный релиз и изменение default branch возвращаются отдельно. Если установленный commit неизвестен, `repository_changed=null`. Автоматической установки нет.

Общий каталог, Docker Compose, nginx и сетевой bootstrap не нужны. Cookies и выгрузки обслуживает локальный runtime. Компьютер и tunnel-client должны работать во время чата; GitHub Pages не запускает MCP.

CI настроен на Linux, Windows и macOS. Полный stdio smoke-тест собирает пакет во временной папке с пробелами в пути, запускает CLI и MCP, проверяет discovery, инструкцию входа, схемы, batch и обновления без реального аккаунта. GitHub Actions на других ОС и реальный аккаунт ChatGPT проверяются отдельно; локальный тест не доказывает их работоспособность.

Проверено локально 16.11.2026: 107 тестов, lint/format, согласованность обоих lock-файлов, структура навыка и самостоятельный stdio smoke-тест прошли. Начальный шаг живого SSO распознан как `emailLogin` без отправки учётных данных. Полный SSO-вход пользователя и ChatGPT Tunnel ещё не проверены.

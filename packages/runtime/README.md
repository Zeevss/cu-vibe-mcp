# CU LMS runtime

Локальное чтение портала ЦУ. `cu-lms-mcp login`, `import-cookie`, `run --stdin`, `methods`, `serve`.

Runtime входит в плагин из GitHub, исполняет методы локально и сохраняет сессию в пользовательской папке данных. Режим `serve --compact` предназначен для MCP-клиентов чата. Полная инструкция находится в README корня репозитория.
